# altfont

A user-interface font for desktop applications, designed for crisp rendering
at small sizes with plain FreeType grayscale or monochrome rasterization
(no subpixel rendering required).

- Styles: Regular, Bold, Italic, Bold Italic (static TrueType, hinted).
- Scripts: Latin (incl. Latin-1, Extended-A, Romanian, Vietnamese), Cyrillic
  (Russian, Ukrainian, Belarusian, Serbian, Macedonian, Bulgarian, Kazakh,
  Uzbek, Tatar, Bashkir, Tajik, Kyrgyz), modern Greek.
- Symbols: punctuation, tabular figures, fractions, super/subscripts,
  currency, math, arrows, geometric shapes, check marks and ballot boxes.
- Tuned for 13 and 15 px (10 and 11 pt at 96 dpi), legible from 11 px.

Specification: [docs/spec.md](docs/spec.md). Build instructions: see
[CLAUDE.md](CLAUDE.md), section "Commands".
