# altfont

A user-interface font for desktop applications, designed for crisp rendering
at small sizes with plain FreeType grayscale or monochrome rasterization
(no subpixel rendering required). Styles: Regular, Bold, Italic, Bold Italic.
Scripts: Latin, Cyrillic, Greek.

Status: planning. See [docs/spec.md](docs/spec.md).
