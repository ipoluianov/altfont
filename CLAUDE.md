# CLAUDE.md

## Project

altfont: a UI font for desktop applications (Regular, Bold, Italic,
Bold Italic; Latin incl. Vietnamese, Cyrillic, Greek, UI symbols).
The main goal is crisp rendering at small UI sizes (11–18 ppem) with stock
FreeType grayscale or monochrome rendering, without subpixel AA.
Full requirements: [docs/spec.md](docs/spec.md). Read it before design or
tooling decisions; update it when a decision changes the requirements.

## Language

- Everything committed to the repository (code, comments, docs, commit
  messages) is in English.
- Talk to the user in Russian.

## Layout

- `src/altfont/` — the font source as Python code:
  `style.py` (metrics and per-style parameters), `glyphs/` (parametric
  glyph definitions: `common.py` registry and helpers, `latin.py`,
  `cyrillic.py`, `greek.py`, `symbols.py` figures and punctuation,
  `signs.py` Latin-1 signs, sub/superscripts, fractions, currency,
  `mathsym.py`, `shapes.py` arrows, geometric and UI symbols, `marks.py`
  diacritics and their placement, `composites.py` accented letters from
  Unicode decompositions), `geometry.py` (shape primitives), `build.py`,
  `fit.py` (pixel fitting), `kern.py` (automatic kerning).
- `src/altfont/fit.json`, `src/altfont/kern.json` — generated, committed.
- `scripts/` — command-line entry points (below).
- `docs/` — specification and design notes.
- `build/` — generated, not committed.

## Commands

Run in this order after changing glyphs, widths or spacing:

1. `python3 scripts/fit.py` — pixel fitting of vertical stems → `fit.json`.
2. `python3 scripts/kern.py` — kerning → `kern.json` (about a minute).
3. `python3 scripts/build.py` — `build/fonts/altfont-<Style>.ttf` (hinted)
   and `*-unhinted.ttf` for Regular, Bold, Italic, BoldItalic.
4. `python3 scripts/check.py` — coverage and sanity checks; must report
   0 problems.
5. `python3 scripts/render.py` — render sheets into `build/render/`
   (HarfBuzz shaping, FreeType rasterizing; modes light, full, mono,
   unhinted); `--blur` prints a crispness metric per size.
6. `PYTHONPATH=.pydeps python3 -m fontbakery check-universal -l WARN
   build/fonts/altfont-{Regular,Bold,Italic,BoldItalic}.ttf` — no FAIL.

## Toolchain

- Python 3 with `fontTools`, `skia-pathops`, `ttfautohint-py`, `freetype-py`,
  `uharfbuzz`, `pillow`, `numpy`, `fontbakery` (see `requirements.txt`).
- The system has no `python3-venv`; dependencies are installed into
  `.pydeps/` (`python3 -m pip install --target .pydeps -r requirements.txt`).
  Scripts add `src/` and `.pydeps/` to `sys.path` themselves, so run them
  with plain `python3 scripts/<name>.py`.

## Working rules

- Judge every outline change by rendered pixels at 11–18 ppem, not by how it
  looks zoomed in. Render sheets in grayscale `hintslight`, `hintfull` and
  mono modes are the source of truth.
- Keep builds reproducible: no manual steps outside `scripts/`.
- Letters with diacritics are not drawn by hand: `composites.py` creates
  them from Unicode decompositions with `accented()`; they inherit spacing,
  width, pixel fit and kerning from the base glyph. New marks go into
  `marks.py`; special placements (apostrophe caron, Greek tonos, horn) are
  handled there and in `composites.py`.
  Letters identical to another script's (Cyrillic а е о р с у х ...) are
  mapped to the same glyph via extra code points, not redrawn.
- Shapes that exist in both cases are written once as `fn(S, w, height)`
  (see `s_shape`, `v_shape` in `latin.py`, `both()` in `cyrillic.py`) and
  registered at x-height and cap height.
- Digits use spacing ("F", "F"): fixed advance `Style.figure_advance`, ink
  centered; the fitter may only shift them.
- Shallow diagonals (< > « ») use the horizontal stem width; with the
  vertical one, Bold strokes get wider than the glyph.
- Italic styles are generated by shearing (`Style.slant`); never add
  italic-only glyph code without updating the spec.
- Source glyph names may contain "-" (`en-cy`); the build writes valid
  production names (`uniXXXX`) into the fonts.
- Combine shapes with `union()` / `|`, not raw `pathops.op` UNION: the
  binary op silently drops parts on coincident edges (stem edge on a curve
  tangent). After adding glyphs, look at a large unhinted render to catch
  such breakage.
- All glyphs are drawn from scratch. Never copy, trace or convert outlines,
  metrics, kerning, anchors, hinting or feature code from other fonts. Other
  fonts are allowed only as visual references and in comparison renders.
- Licensing: fonts are OFL 1.1 (`OFL.txt`), scripts are MIT (`LICENSE`).
